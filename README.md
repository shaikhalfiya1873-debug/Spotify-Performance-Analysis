# 🎵 Spotify Music Performance Dashboard \| Power BI

## 📊 Project Overview

I created an **interactive Spotify Music Performance Dashboard using
Microsoft Power BI** to analyze music streaming performance across
artists, genres, release years, countries, and platform types.

The dashboard transforms raw Spotify data into an easy-to-understand
analytical report with interactive filters, KPI cards, charts, and a
detailed artist-level performance table.

------------------------------------------------------------------------

## 🎯 Project Objectives

-   Analyze total music streams and listener performance
-   Compare streaming performance across different genres
-   Identify artists with higher streaming volumes
-   Analyze trends by release year
-   Compare monthly listeners by platform type
-   Examine average stream duration and skip rate
-   Build an interactive dashboard for business-style music analytics

------------------------------------------------------------------------

## 🛠️ Tools & Technologies

-   **Microsoft Power BI**
-   **Power Query** -- Data cleaning and transformation
-   **DAX** -- Measures and KPI calculations
-   **Data Visualization** -- Interactive charts, cards, slicers and
    tables
-   **Spotify Dataset** -- Music and streaming performance data

## 📌 Dashboard KPIs

The dashboard includes the following key performance indicators:

  KPI                          Description
  ---------------------------- ----------------------------------------
  🎧 Total Streams             Overall number of streams
  🎤 Count of Artists          Number of artists represented
  ⏱️ Average Stream Duration   Average duration of streams in minutes
  🌍 Count of Countries        Number of countries represented
  👥 Total Monthly Listeners   Overall monthly listener count

------------------------------------------------------------------------

## 📈 Dashboard Visualizations

### 1. Total Streams by Genre

A column chart comparing streaming volume across music genres such as
Classical, Rock, K-pop, EDM, Pop, R&B, Hip-Hop, Reggae and Jazz.

### 2. Total Streams by Release Year

A line chart showing how total streams vary across release years and
helping identify changes in streaming performance over time.

### 3. Total Streams by Artist

A horizontal bar chart highlighting artists with higher total stream
counts.

### 4. Monthly Listeners by Platform Type

A donut chart comparing monthly listeners across **Free** and
**Premium** platform users.

### 5. Artist Performance Table

A detailed table containing: - Artist - Total Streams - Average Stream
Duration - Average Skip Rate

Conditional formatting is used to make performance differences easier to
identify.
